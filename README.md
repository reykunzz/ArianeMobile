# Ariane Mobile — Android port workspace

Target: **GTA San Andreas Classic Mobile**, Android **ARM64 only**.

This is an Android port scaffold, not yet a complete Ariane port. It includes a Kotlin shell, JNI bridge, OpenGL ES 3 viewport, SAF folder picker, starter text IPL `inst` parser, IMG v2 directory parser, and GitHub Actions APK build.

See [README-GITHUB-TERMUX.md](README-GITHUB-TERMUX.md) for the phone-first build workflow and [docs/porting-status.md](docs/porting-status.md) for upstream integration status.

Do not commit copyrighted GTA game archives/assets to a public repository.
